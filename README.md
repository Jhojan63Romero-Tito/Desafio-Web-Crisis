Simulador de Precios de Alimentos y Compras Familiares

Descripción del Proyecto

Este proyecto fue desarrollado para la materia de Programación Web I y tiene como objetivo simular problemas económicos que afectan a las familias debido al incremento de precios de productos básicos de la canasta familiar.

La aplicación web permite analizar cómo el aumento de precios impacta en el gasto mensual de una familia y verificar si un presupuesto determinado es suficiente para realizar las compras necesarias.

Mediante formularios interactivos y cálculos automáticos realizados con JavaScript, el usuario puede ingresar datos reales o simulados para obtener resultados inmediatos sobre su situación económica.

Problema Abordado

En la actualidad, el aumento de precios de productos como arroz, azúcar, aceite y papa afecta directamente el presupuesto de los hogares. Muchas familias deben reorganizar sus gastos para cubrir sus necesidades básicas.

Este simulador busca representar de manera sencilla cómo estos cambios influyen en la economía familiar.

Funcionalidades

Simulador de Precios de Alimentos

Permite calcular:

* Incremento de precio.
* Porcentaje de aumento.
* Gasto anterior.
* Gasto actual.
* Diferencia de gasto.

Simulador de Compras Familiares

Permite calcular:

* Total de la compra.
* Saldo restante.
* Monto faltante.
* Estado del presupuesto.

Casos de Estudio

Se incluyen ejemplos basados en productos de la canasta familiar para verificar el correcto funcionamiento del sistema.

Ejemplo:

* Arroz: 8 Bs → 11 Bs
* Papa: 7 Bs → 10 Bs
* Aceite: 12 Bs → 18 Bs
* Presupuesto familiar: 500 Bs

Conclusiones

El desarrollo de este proyecto permitió aplicar conceptos fundamentales de Programación Web I, incluyendo el uso de HTML5 semántico, estilos con CSS3, diseño responsivo mediante Bootstrap, manipulación del DOM y programación con JavaScript.

Además, el simulador ayuda a comprender de forma práctica cómo los cambios en los precios de los productos básicos pueden afectar el presupuesto y el poder adquisitivo de las familias.
